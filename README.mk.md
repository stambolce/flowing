## Што е FLOWING?

## Статус и пристап

FLOWING е приватна интерна платформа на PROCESS IN. Јавна самостојна проверка на домен, Google Web Risk, дополнителни email репутациски анализи и автоматизирани понуди се дел од поширокиот развоен опфат и не се претставуваат како јавно достапни услуги. Техничкиот сигнал не е доказ за компромитација без дополнителна проверка.
